# notes-forge

Turn rough study notes into clear, correct, well-structured notes — with sources and diagrams.

You paste in what you wrote while learning something. notes-forge reads it, figures out what's
missing or wrong, researches the gaps, and rewrites the notes so they still sound like you.

> Work in progress.

## Setup

```bash
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env   # add your API key
```
